# Codex project context

- Work with Phạm Tiến Đạt in Vietnamese. Keep the site's Vietnamese and English versions equally natural and professional.
- Read `docs/brief.md`, `docs/evidence.md`, and `docs/references.md` before changing content or design.
- The working application is Next.js in `app/`, `components/`, and `lib/`. `npm run build` creates the static export in `out/`. Keep VI and EN routes, metadata, and interactions working when refactoring.
- The user wants the actual structure and motion of reference sites examined. Open and scroll them with a working browser before claiming to have studied their animations. Apply only patterns relevant to an SEO portfolio.
- Use the `design-taste-frontend` skill when available.
- Avoid generic marketing copy, invented achievements, and charts implying one person caused sitewide growth. Public case data is aggregate GSC evidence without identifying the client.
- Check desktop and mobile layout, VI/EN switch, keyboard use, focus states, contact and published article links, and `prefers-reduced-motion` after meaningful edits.
- This repository is a source handoff; preview and review changes before any live deployment.
