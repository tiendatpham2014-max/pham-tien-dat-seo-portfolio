# Nguồn tham khảo và phần đã áp dụng

Các URL dưới đây do chủ portfolio cung cấp để định hướng bố cục và chuyển động. Website dùng HTML/CSS/JavaScript của dự án; không đưa mã nguồn, hình ảnh hoặc nội dung demo trả phí vào repo. `docs/IMPLEMENTATION_DECISIONS.md` ghi quyết định chi tiết và `docs/SOURCE_MAP.md` chỉ nơi sửa code.
