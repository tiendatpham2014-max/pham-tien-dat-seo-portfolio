# Theme variant: Editorial Fluid

Branch: `theme-editorial-fluid`

This is a separate visual direction for the same SEO portfolio, with its own complete Next.js source. It can evolve independently and be compared with the production design on `main`.

The source-owned design includes a fluid Hero background, the owner's signature artwork, a scroll-controlled career horizon, a three-part SEO project scene, sitewide GSC evidence with team attribution, bilingual copy, and light/dark themes. The intro signature replays on page refresh; direct section links and reduced-motion preferences skip it.

To view locally, run `npm ci`, `npm run build`, and `npm run preview` from this branch. `vercel.json` disables automatic Vercel deployments for this theme branch until its design is selected for publication.
